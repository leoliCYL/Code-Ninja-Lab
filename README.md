# Code-Ninja-Lab: Hand Gesture Tracking
A Python-based computer vision project using OpenCV and MediaPipe Tasks API to detect and count fingers in real-time.

## Tech Stack
* **Language:** Python 3.11+
* **Libraries:** OpenCV, MediaPipe
* **Hardware:** Tested on MacBook Pro (M-series)

## Setup
1. Clone the repo.
2. Install dependencies: `pip install -r requirements.txt`.
3. Download `hand_landmarker.task` and place in root.
4. Run `python main.py`.
